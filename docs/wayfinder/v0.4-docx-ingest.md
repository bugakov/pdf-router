# Wayfinder map — v0.4 docx ingest

## Destination

docx works end-to-end: `convert("документ.docx")` emits the same quality LLM/RAG
material as PDF (md/chunks/json renderers, structural blocks, sidecar images),
parsed **natively** — no external binaries, no heavy dependencies — verified on
real docx from the kotel-zamechanna / fin-fine corpora and committed.

## Notes

- Domain: `pdf-router` Python project (uv, Python ≥ 3.12); sole consumers are
  local RAG indexing pipelines. Ethos: "ultra-minimal, deterministic,
  deploy-anywhere" (`pyproject.toml` description).
- Skills to consult per session: `grilling` (one question at a time),
  `domain-modeling` (when a term graduates), `research` subagent (for
  outside-knowledge tickets).
- Standing preferences (locked across the effort, do not re-litigate):
  - **No external binaries in the docx dependency path.** LibreOffice→PDF
    conversion rejected by the user 2026-09-12 ("оскорбительно нерационально,
    абсурдно и расточительно" — double quality loss: structure flattened to
    glyphs, then re-derived by heuristics). pandoc allowed only as an offline
    quality benchmark in research, never as a dependency.
  - **Native parse is the baseline.** stdlib zipfile+ElementTree adapter
    (architecture-report candidate 3) stands unless TKT-DX-01 finds a
    qualifying ready-made tool.
  - **Scanned docx is not expected** (user, 2026-09-12); no OCR path for docx
    in this effort — type it honestly in metadata if encountered.
  - No premature abstractions; flat functions; one file over many; tunables in
    TOML config (v0.3 map Notes carry over).
  - The format dispatch seam is locked (commit 57cfa1f): magic-byte detect →
    `Inspector` registry in `src/pdf_router/formats.py`; a docx inspector is
    one registry entry, nothing downstream changes by itself.
  - Images stored as paths to PNG/source files in a sidecar folder, not base64
    in IR (TKT-RT-08).
- Empirical baseline (probed 2026-09-12): 68 real docx under
  `/home/scanum/kotel-zamechanna/` and `/home/scanum/fin-fine/data/docs/`;
  representatives are text/table-rich, image-light (0–2 media files per doc);
  no scan-typical docx in the corpus.
- Environment: `uv run python` / `uv run pytest` (bare `python` not in PATH);
  fast tests `uv run pytest -q -m "not slow"`; never run two pytest runs in
  parallel; the user commits via `gaa && forge commit && gp` — leave all
  changes uncommitted.
